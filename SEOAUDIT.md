## Suggested Improvements

Ordered by impact-to-effort ratio (highest first):

### 1. Fix duplicate step runner registrations (correctness fix, effort: S)

**What:** `pipeline/steps.ts` lines 1118-1136 re-register 4 step runners, overwriting the real ones. When using `seoflow orchestrate`, technical-audit, fact-check, and report-export run stubs instead of real pipeline logic.

**Why matters:** Orchestrator mode silently produces empty results for these steps.

---

### 2. Fix missing imports in `pipeline/technical.ts` (correctness fix, effort: S)

**What:** Line 9 only imports 2 functions from `broken-links.ts` but calls 5 that aren't imported. ReferenceError at runtime (silently caught).

**Why matters:** Technical audit silently skips canonical, hreflang, sitemap, robots.txt, and mobile-friendly checks for every post.

---

### 3. Delete dead files (architecture cleanup, effort: S)

**Files to delete:**
- `lib/surfer-client.ts` — empty stub
- `lib/claude-client.ts` — superseded by `lib/providers/anthropic.ts`
- `lib/gemini-client.ts` — superseded by `lib/providers/gemini.ts`
- `lib/openrouter-client.ts` — superseded by `lib/providers/openrouter.ts`
- `lib/cli/cli.ts` — unused, separate CLI implementation
- `lib/flow/framework.ts` — never imported
- `lib/business-types/overlays.ts` — never imported
- `scripts/` directory — duplicate of `python/`

**Why matters:** Confuses new contributors, wastes disk space (51 duplicate files), makes grep results noisy. The old client files could mislead someone into editing the wrong one.

---

### 4. Add test coverage for orchestrator and providers (missing test coverage, effort: M)

**What:** Zero tests for `lib/orchestrator/`, `lib/providers/`, `lib/brain/brain-manager.ts`, `lib/url-auditor.ts`, `lib/structured-output.ts`, `lib/degradation.ts`.

**Why matters:** These are the newest modules and have no regression protection. A refactor or bug fix in provider selection could silently break all AI-dependent features.

---

### 5. Fix report scoring (correctness fix, effort: S)

**What:** `pipeline/report-export.ts` line 31 hardcodes `score: 85`. Should compute from actual step results.

**Why matters:** All exported reports show score 85 regardless of actual audit quality.

---

### 6. Update docs to match code (doc-code mismatch, effort: M)

**What:** 6 doc claims that don't match reality (npm script names, `publish --go` syntax, missing commands). Also: INTEGRATION_PLAN.md phases marked `[ ]` are actually implemented. New commands (orchestrate, brain, vault) undocumented.

**Why matters:** New users following docs will get errors. Anyone reading INTEGRATION_PLAN.md won't know what's already built.

---

### 7. Fix or remove ahrefs/semrush Python script references (correctness fix, effort: S)

**What:** `lib/ahrefs-client.ts` and `lib/semrush-client.ts` call Python scripts that don't exist (`ahrefs_keywords`, `semrush_keywords`). Both silently degrade to empty fallback.

**Why matters:** If someone sets `AHREFS_API_KEY` expecting it to work, it silently does nothing.

---

### 8. Add Ubersuggest real-time API call (new capability, effort: M)

**What:** `lib/ubersuggest-client.ts` only reads from a JSON cache file and requires manual MCP invocation. No automatic API fallback.

**Why matters:** Step 0 (keyword research) produces empty results for users without SEMrush/Ahrefs keys, which is the majority of users.

---

### 9. Remove duplicate `scripts/` directory (architecture cleanup, effort: S)

**What:** Delete `scripts/` (51 files, exact copy of `python/`).

**Why matters:** Zero TypeScript code references `scripts/`. Keeps one source of truth for Python scripts. Frees ~500KB.
