Questions

Do I need API keys to try SeoFlow?

No. A URL audit runs with zero API keys. Content generation and the other AI-driven steps need one key from any supported provider.

Which AI providers does SeoFlow support?

Gemini, OpenRouter, Anthropic, any OpenAI-compatible endpoint, and local CLI agents. Add one key and the pipeline runs; missing keys just skip that step.

How is this different from Surfer or Clearscope?

Surfer and Clearscope are hosted dashboards with per-seat pricing and a locked-in AI provider. SeoFlow is an MIT-licensed CLI tool that runs in your own repo, with your own AI key, and no monthly cost.

Does my content or site data leave my machine?

No. SeoFlow runs locally against your repo. The only outbound calls are to the AI provider and data sources you configure yourself.

Is SeoFlow really free?

The tool is free and MIT-licensed. You only pay for whichever AI provider you connect, at that provider's own rates.
